# 협업/문서 도구 차용 리포트 — AFFiNE · AppFlowy

> 목적: 우리 플랫폼 엔지니어링 포털의 협업/지식 페이지(업무·할일·문서·마인드맵·워크플로우)를
> AFFiNE / AppFlowy 와 비교해 **실무에 도움되는 것만** 차용·고도화하기 위한 기준.

## 영역별 메모
- **업무/할일**: 같은 데이터·여러 뷰 + 저장된 뷰, 그리드 인라인 편집, 임의 필드 그룹핑 보드, 상세 상단 속성 패널, 반복 작업/용량.
- **추가 기능**: 댓글·@멘션·변경 이력(가장 큰 협업 결손), 백링크, 에디터 내부 링크.
- **문서 템플릿**: 템플릿 갤러리 + "새 문서→템플릿", 문서 속성(front-matter). → 아래 "실무 템플릿" 참고.
- **마인드맵**: 내보내기, 서브트리 접기, 노드 리치텍스트, 노드↔업무/문서 변환, AI 생성.
- **워크플로우**: 스텝↔업무 연동 자동 진행(referenceType/Id 활용), 스윔레인, 워크플로우 템플릿, 보드 뷰.

## 실무 우선 템플릿(엔지니어/운영) — 군더더기 없이 꼭 필요한 것만
1. **작업 계획서** — 목적/범위/대상/사전점검/실행절차(체크리스트)/롤백/검증/영향도/일정/담당
2. **이슈 대응 문서** — 발생일시·심각도·영향범위·증상·타임라인·원인(임시/근본)·조치·재발방지·관련링크
3. **운영 대응 양식(런북)** — 상황·점검항목·대응절차·확인명령어·에스컬레이션
4. **스터디 정리** — 주제·핵심요약·개념·실습/명령·참고·TODO
5. **명령어 관리(표)** — 명령어 | 설명 | 비고 (엑셀처럼 표 관리)
6. **구조도 문서** — 도식(draw.io 임베드) + 설명 *(diagram 임베드 도입 후)*

## 문서 기능 고도화(코드 적용 방향)
- **이미지 용량 관리**: ✅ **적용 완료** — `src/lib/imageCompress.ts` 의 `compressImageFile`
  (캔버스 다운스케일 maxDim=1600 + webp/jpeg 재인코딩, 200KB 미만 스킵)이 RichTextEditor
  붙여넣기 경로에서 이미 동작 중. (서버 업로드+URL 참조는 여전히 후속 옵션)
- **.md import**: 마크다운 파일 → 에디터 본문 변환(경량 파서). *(미구현)*
- **draw.io/diagrams.net 임베드**: PNG 가 아니라 **.drawio XML / SVG(벡터)** 로 저장해 경량 유지. *(미구현)*
- **엑셀형 표 관리**: TipTap 표 강화(행/열 추가·정렬, CSV 붙여넣기) 또는 데이터그리드 블록. *(미구현)*
